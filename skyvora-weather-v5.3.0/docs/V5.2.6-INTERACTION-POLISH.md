# Skyvora Weather V5.2.8 — Interaction Polish

## Changes
- Mobile sidebar Search now closes the drawer before focusing the topbar search field and positions the autocomplete panel after focus.
- The forecast question action is explicitly a submit button with a stable label, accessible name, and consistent tap target.
- 24-hour forecast cards use a smoother, restrained hover lift and icon response on hover-capable devices.
- Wind compass needle performs one 360-degree sweep on pointer hover and finishes at the provider-reported wind bearing.
- Daylight path reveals smoothly; the sun has restrained glow, breathing and hover-ray motion.
- Air-quality gauge, pollutant cards and sparklines use subtle entrance and hover transitions.
- Reduced-motion preferences disable the added animations and transitions.

## QA status
Automated static tests and project checks are run for this release. Real browser/device visual inspection and live provider verification must be completed in the target environment before calling the release production-ready.
