# Skyvora Weather V5.2.4 — Search Interaction Fix

## Changes
- Removed `preventDefault()` from result `pointerdown`; cancelling pointerdown can suppress the synthesized click on touch devices.
- Result selection is handled by a dedicated click listener and stops propagation to prevent duplicate selection.
- On narrow screens, the results panel is fixed to the viewport gutters rather than constrained by the narrow search input/grid column.
- The panel position is calculated from the input's viewport rectangle and recalculated on resize/scroll/visual viewport resize.
- Hiding the panel clears temporary inline positioning styles.

## Important distinction
A `502 Bad Gateway` on `/api/weather/forecast` is a weather-provider/backend request failure. It is separate from the geocoding search interaction. The app should show a clear forecast error/retry state; this release does not claim that an upstream provider outage has been eliminated.

## Verification
Run `npm test`, `npm run check`, and `npm run audit:production`. Also verify touch selection and keyboard selection in Chrome at 293px, 375px, 768px, and desktop widths. A real external API test and Lighthouse run require the user's network/runtime.
