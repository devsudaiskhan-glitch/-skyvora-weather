# Skyvora Weather V5.2.0 — Performance Notes

## Changes targeting the reported Lighthouse bottlenecks

1. **LCP / initial render:** the app now validates and hydrates a last-known forecast from local storage before starting the live forecast request. First-time visitors receive the dashboard shell immediately while weather data loads in the background.
2. **Main-thread work:** dashboard chart SVG generation and secondary icon hydration are deferred until after the browser has had an opportunity to paint the primary dashboard.
3. **Font request chain:** the initial Google Fonts stylesheet and preconnect hints have been removed. The app uses a system font stack so rendering does not depend on `fonts.googleapis.com` or `fonts.gstatic.com`.
4. **Image delivery:** scenic images use a smaller 1000px / quality-58 rendition. Only the currently active day or night scene background is requested, and the eager JavaScript image preloader has been removed.
