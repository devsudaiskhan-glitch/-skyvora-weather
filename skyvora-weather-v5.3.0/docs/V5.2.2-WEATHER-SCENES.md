# Skyvora Weather V5.2.2 — Dynamic Weather Scenes

The dashboard background now selects a separate day/night photograph using the current Open-Meteo WMO weather code. Scene classes include clear, partly cloudy, overcast, drizzle, rain, heavy rain, thunderstorm, snow/freezing precipitation, fog, and high-wind clear conditions.

The scene image is decorative photography from Unsplash, not a live camera, satellite image, or radar layer. The active day/night layer is requested by CSS; the inactive layer is disabled by the existing app stylesheet. Images require an internet connection.

Day/night selection continues to use provider `is_day` data and falls back to local sunrise/sunset data when available. High-wind scenery is selected only for otherwise clear weather at wind speeds of 45 km/h or more.

Validation: automated test suite, project checks, and static production asset audit were run for this source package. A browser visual check and fresh Lighthouse run were not performed in this environment.
