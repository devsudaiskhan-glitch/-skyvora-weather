# Skyvora Weather V5.2.5 — Search Panel Portal Fix

## Root cause
The search dropdown was nested inside the sticky `.topbar`, which uses `backdrop-filter`. That property creates a containing block for fixed-position descendants. Earlier mobile CSS changes therefore could not reliably position the dropdown against the viewport, causing it to remain constrained to the narrow search area.

## Changes
- Move the existing search results element to `document.body` while preserving its event listeners and `aria-controls` relationship.
- Position the panel from the search input's viewport rectangle.
- Use viewport gutters on compact screens and a bounded input-aligned panel on larger screens.
- Keep clicks inside the portalled panel from being treated as outside clicks.
- Add regression checks for the portal and fixed viewport positioning.

## Verification
Automated tests, static project checks and production asset audit are run for this release. Real browser/mobile interaction and live provider API checks must still be performed in Chrome on the target machine.
